## Selected Projects

### JARVIS-style AI Personal Assistant
A personal assistant built with **n8n** that connects to Gmail, Google Calendar, Docs, Sheets, web research, Reddit, Hacker News, GitHub, weather, maps, web scraping, monitoring (job postings, price changes), Excel export and Telegram. It has a custom website interface with typed and voice input using browser speech APIs.

I started with a multi-agent architecture, but 60-90 second responses and agent loops pushed me to a flatter design, which brought responses down to single-digit seconds. I also experimented with self-hosted **Ollama** models.

`n8n` `AI Agents` `Ollama` `Telegram` `Browser Speech APIs`

### FluentAI
A language-learning AI platform built by **Team CodeWithMay** for the Language track of the Adaption AutoScientist Challenge x HackIndia. It includes a voice coach with speech recognition and text-to-speech, 12 languages, 9 conversation modes (interview prep, IELTS, business, debate), grammar checking, translation with confidence scoring, AI vocabulary lookup, a provider abstraction layer with local-model / AutoScientist model switching, and a dataset export pipeline.

### VibeFlow AI
A real-time medical conversational avatar platform built for HackIndia 2026. It supports English, Hindi and Hinglish, with emotion detection, intent classification and multiple AI personas. I generated synthetic patient-AI conversations and built a dataset of **1,018+ real + synthetic medical dialogues** with Adaption, exported to Kaggle.

### AI Fact-Verification App
A Flutter app that verifies text and images (with OCR) against multiple external sources, including Google Fact Check, Wikipedia, news APIs, WHO, UN and PIB. It produces verdicts, confidence scores, source breakdowns and explanations.

`Flutter` `Node.js` `Express` `GPT OSS 120B` `LLaMA 3.1` `OCR`

### MediaGrab
A full-stack media downloader supporting platforms such as YouTube, TikTok, Instagram and Pinterest. It shows real-time download progress over **Server-Sent Events**, handles background processing, and cleans up temporary files. The UI is platform-aware.

`React` `Tailwind CSS` `Node.js` `Express` `yt-dlp` `SSE`
